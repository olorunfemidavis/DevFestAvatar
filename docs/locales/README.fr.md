DevFestAvatar est une application web légère pour créer des avatars de profil DevFest 2026. Les utilisateurs importent une photo, choisissent un cadre DevFest, puis téléchargent ou partagent le résultat. Le flux standard s'exécute directement dans le navigateur.

Application en direct : [https://devfestavatar.web.app](https://devfestavatar.web.app)

<img src="../../public/images/icons/logos/wide.png" width="400" alt="DevFestAvatar logo">

## Fonctionnalités

- Importez, cadrez, téléchargez et partagez des avatars DevFest.
- Interface inspirée des visuels imprimés DevFest 2026 avec prise en charge des thèmes clair et sombre.
- Conception responsive pour smartphones, tablettes et ordinateurs.
- Mode optionnel d'édition d'image avec Gemini via Firebase Functions.

## Développement Local

```powershell
http-server ./public -p 8081
```

Ouvrez l'URL affichée par `http-server` dans votre navigateur.

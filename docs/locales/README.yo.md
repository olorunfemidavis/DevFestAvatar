DevFestAvatar jẹ́ wẹ́ẹ̀bù alátẹjú fún ṣíṣèdá àwòrán prófílì DevFest 2026. Àwọn oníṣe ń tẹ àwòrán síbẹ̀, wọ́n ń mu fírẹ́ẹ̀mù DevFest, wọ́n sì ń gba àwòrán náà síbẹ̀ tàbí pín in.

Wẹ́ẹ̀bù lórí ẹ̀rọ: [https://devfestavatar.web.app](https://devfestavatar.web.app)

<img src="../../public/images/icons/logos/wide.png" width="400" alt="DevFestAvatar logo">

## Àwọn Nǹkan Tó Wà Níbẹ̀

- Tẹ àwòrán, ṣètò fírẹ́ẹ̀mù, gba síbẹ̀, àti pín àwòrán prófílì DevFest.
- Àwọn ìrísí tó dára fún fónù, àtẹ alátèjáde, àti kọ̀m̀pútà.
- Lóòrè fún àwọ̀ pípọ́n (light mode) àti àwọ̀ dídán (dark mode).

## Ìgbésẹ̀ lórí Ẹ̀rọ yín (Local Development)

```powershell
http-server ./public -p 8081
```

Ṣí URL náà nínú ẹ̀rọ wẹ́ẹ̀bù rẹ.

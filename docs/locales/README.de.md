DevFestAvatar ist eine leichtgewichtige Web-App zur Erstellung von DevFest 2026 Profil-Avataren. Benutzer laden ein Foto hoch, wählen einen DevFest-Rahmen und laden das Ergebnis herunter oder teilen es. Der Standard-Flow läuft direkt im Browser.

Live-App: [https://devfestavatar.web.app](https://devfestavatar.web.app)

<img src="../../public/images/icons/logos/wide.png" width="400" alt="DevFestAvatar logo">

## Funktionen

- DevFest-Avatare hochladen, zuschneiden, einrahmen, herunterladen und teilen.
- Vom DevFest 2026 Design inspiriertes Interface mit Unterstützung für Hell- und Dunkelmodus.
- Responsives Layout für Smartphones, Tablets und Desktop-PCs.
- Optionaler Gemini KI-Bearbeitungsmodus über Firebase Functions.

## Lokale Entwicklung

```powershell
http-server ./public -p 8081
```

Öffnen Sie die vom `http-server` ausgegebene URL im Browser.

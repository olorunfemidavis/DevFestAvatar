DevFestAvatar هو تطبيق ويب خفيف لإنشاء الصور الرمزية لملفات التعريف لـ DevFest 2026. يقوم المستخدمون بتحميل صورة، واختيار إطار DevFest، ثم تنزيل النتيجة أو مشاركتها.

التطبيق المباشر: [https://devfestavatar.web.app](https://devfestavatar.web.app)

<img src="../../public/images/icons/logos/wide.png" width="400" alt="DevFestAvatar logo">

## الميزات

- تحميل وقص وتأطير وتنزيل ومشاركة صور DevFest الرمزية.
- واجهة مستوحاة من مطبوعات DevFest 2026 مع دعم الوضع الفاتح والداكن.
- تصميم متوافق مع الهواتف والأجهزة اللوحية وأجهزة الكمبيوتر.
- وضع تعديل الصور الاختياري بـ Gemini عبر Firebase Functions.

## التطوير المحلي

```powershell
http-server ./public -p 8081
```

افتح الرابط المطبوع بواسطة `http-server` في متصفحك.

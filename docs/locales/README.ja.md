DevFestAvatar は、DevFest 2026 プロフィール画像を作成するための軽量 Web アプリです。写真をアップロードし、DevFest フレームを選択して、ダウンロードまたは共有できます。

ライブアプリ: [https://devfestavatar.web.app](https://devfestavatar.web.app)

<img src="../../public/images/icons/logos/wide.png" width="400" alt="DevFestAvatar logo">

## 機能

- DevFest アバターのアップロード、切り抜き、フレーム設定、ダウンロード、共有。
- ライト/ダークテーマに対応した DevFest 2026 インターフェース。
- スマホ、タブレット、PC に対応したレスポンシブデザイン。
- Firebase Functions を介した Gemini AI 画像編集モード。

## ローカル開発

```powershell
http-server ./public -p 8081
```

`http-server` が出力した URL をブラウザで開きます。

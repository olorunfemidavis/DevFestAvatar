O DevFestAvatar é uma aplicação web leve para criar avatares de perfil do DevFest 2026. Os usuários enviam uma foto, escolhem uma moldura do DevFest e baixam ou compartilham o resultado. O fluxo padrão roda diretamente no navegador.

Aplicação ao vivo: [https://devfestavatar.web.app](https://devfestavatar.web.app)

<img src="../../public/images/icons/logos/wide.png" width="400" alt="DevFestAvatar logo">

## Recursos

- Envie, recorte, enquadre, baixe e compartilhe avatares do DevFest.
- Interface inspirada na identidade visual do DevFest 2026, com suporte a temas claro e escuro.
- Layout responsivo para celulares, tablets e computadores.
- Modo opcional de edição de imagem com Gemini via Firebase Functions.

## Desenvolvimento Local

```powershell
http-server ./public -p 8081
```

Abra a URL exibida pelo `http-server` no seu navegador.

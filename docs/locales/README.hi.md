## विशेषताएं

- DevFest अवतार अपलोड, क्रॉप, फ्रेम, डाउनलोड और शेयर करें।
- लाइट और डार्क थीम सपोर्ट के साथ DevFest 2026 इंटरफेस।
- फोन, टैबलेट और लैपटॉप के लिए उत्तरदायी लेआउट।
- Firebase Functions के माध्यम से वैकल्पिक Gemini इमेज एडिट मोड।
